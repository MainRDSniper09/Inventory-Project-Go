# Código de conducta

Este proyecto adopta el [Contributor Covenant 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

En resumen: sé respetuoso, acepta la crítica constructiva, enfócate en lo mejor para la comunidad y muestra empatía. El acoso o lenguaje ofensivo no se tolera.

Los incidentes pueden reportarse de forma privada a los mantenedores a través de GitHub. Toda queja será revisada con confidencialidad.
