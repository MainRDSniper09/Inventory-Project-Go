# Política de seguridad

## Versiones soportadas

Sólo la última versión publicada recibe correcciones de seguridad.

## Reportar una vulnerabilidad

**No abras un Issue público.** Usa el botón *"Report a vulnerability"* en la pestaña **Security** del repositorio (GitHub Private Vulnerability Reporting). Responderemos en un plazo razonable y coordinaremos la divulgación.

## Estado actual (v0.1.0)

El MVP **no tiene autenticación**: está pensado para uso local o en una red de confianza. No lo expongas a Internet sin un proxy inverso con autenticación. La autenticación y los roles están planificados para v0.2.0 (ver [ROADMAP](docs/ROADMAP.md)).
